# annarotkirch.com

Source and build for Anna Rotkirch's personal site.

- `content/` — page text in Markdown, one file per page. Edit here.
- `build_site.py` — builds the site. Run `python3 build_site.py` after any edit.
- `docs/` — generated output, served by GitHub Pages. Do not edit by hand.

The Media page is generated from the CSV files in the parent folder; it is never edited directly.
